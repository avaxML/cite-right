# openwiki/

Agent wiki for cite-right, generated by [OpenWiki](https://docs.langchain.com/oss/openwiki/overview) 0.4.0.

`INSTRUCTIONS.md` is the user-authored brief. OpenWiki reads it on every run and does not overwrite it.

Generated pages, Grounded Claims under `.claims/`, and `.last-update.json` appear after the `OpenWiki Update` GitHub Action runs with repository secret `OPENROUTER_API_KEY`. Until that first run, this directory is only the brief and this stub.

Coding agents: read `INSTRUCTIONS.md` for invariants. Once pages exist, start there instead of rediscovering the tree.
